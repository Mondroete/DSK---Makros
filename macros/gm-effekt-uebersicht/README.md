# GM Übersicht

Die GM Übersicht hilft dem Spielleiter, eine Übersicht der laufenden Effekte zu bekommen und jene schneller von Akteuren zu löschen oder zu bearbeiten. Selbst auf die Akteurbögen kann man so schneller zugreifen.
